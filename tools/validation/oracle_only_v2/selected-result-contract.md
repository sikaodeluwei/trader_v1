# Approved comparison representation contract (no recognition implementation)

Use this schema with the copied approved course specifications. This file provides representation fields only, not oracle answers or production algorithms. Every index is zero-based in the frozen 250-bar window. Original timestamps are UTC close labels; analyzer/oracle clock is close minus five minutes. Case identity and exact source bindings are in provenance/source-bindings.json.

Source numerical data is sources/wNN.csv, exactly copied from frozen inputs. provenance/freeze-manifest.json has external SHA256 ce048e298e2eb0eb5f82cec2cb34ac14f5db277997b3399e27f910d4581dc6ac. Its other original artifact paths are provenance references, not files to look up outside this workspace. No production modules or results are provided.

selection.json top fields: schema=MNQ_CONTEXT_SELECTION_V1, cohort_id=mnq-202609-5m-v2, frozen_manifest_sha256, policy_sha256 (hash of rules/CONTEXT_SELECTION_V1.md), contexts (ordered list), coverage (list).
Each context has exactly context_id, source (complete copied binding), segment={start_index,end_index,level}, bms=null or {trend_origin_index,previous_extreme_index,pullback_extreme_index}, sms=null or {creator_point_index,trend_extreme_index}, rationale (independent explicit choice).
Levels are short/medium/long, not timeframes. Context IDs are lowercase alphanumeric/underscore/hyphen, max96, unique. Source references must match copied bindings. Request indexes lie in0..249. Valid and deliberate negative contexts must be distinguished in rationale, without changing the numeric request schema.
Coverage records have exactly requirement, disposition=covered/absent/ambiguous, context_ids, rationale, synthetic_fixture (null or reference). Absent cases have no context IDs and cite a synthetic fixture; do not fabricate natural examples. Freeze any discretionary ambiguities/alternatives separately rather than inventing an exact answer.

expectations.json is a dictionary keyed by context_id. Each value has exactly request, selected_points, market_state, bms, sms, trend_start_anchor.
request has exactly segment (with level inside it), bms, sms, matching numeric request fields.
Every selected point and non-null anchor has {level,point,source_vertex}. point={index,kind,price}; kinds high/low; prices canonical decimal strings (e.g.130, not130.0; no rounding/tolerance). SHORT source_vertex={index,kind,price,recognition_basis}; basis strict/right_inside_bar or null only when defined. MEDIUM source_vertex={pivot:SHORT vertex,confirmed_by:SHORT vertex}. LONG source_vertex={pivot:MEDIUM vertex,confirmed_by:MEDIUM vertex}. Preserve complete nested provenance; point geometry must equal its source pivot. Full previous same-kind evidence remains in hierarchy oracle files under their existing schema.
market_state={status,reason,value}; status available/unavailable/invalid. Available reason=null and value uptrend/downtrend/non_trend; unavailable/invalid value=null with exact reason.
bms/sms=null when not requested; otherwise {status,reason,value}. Available BMS value={status:pullback_only/bms_confirmed/not_a_pullback,broken_extreme:null or point,breakout_index:null or integer}. Available SMS value={status:pending/pullback_only/sms_confirmed/parent_continued,broken_point:null or point,event_index:null or integer}. Nonterminal values have null event fields. Invalid/unavailable value=null. Reasons include insufficient_structure, boundary_not_canonical_vertex, invalid_context, parent_state_not_directional, ohlc_intrabar_order_ambiguous. No diagnostic prose is compared.
trend_start_anchor is null when absent, otherwise complete SHORT resolved provenance separate from selected-level points. The rules specify its eligibility; the schema supplies no label.

Hierarchy expected JSON retains the accepted independent builder's rich format, case_id overridden by the copied successor binding and source_binding attached. Serialize hashes deterministically. Use exact MNQ quarter-tick prices; lossless float representation in the accepted independent builder is permitted only if Decimal.from_float equals the original Decimal. Keep both source close and mapped start clocks explicit in reproduction metadata. Never run/import/read production recognition or historical project/oracle outputs.
